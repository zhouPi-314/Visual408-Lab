# 托管方案与免费域名评估

> 目标：以最低成本拿到可公开访问的地址，并让部署可复现。本项目是纯静态站点（`apps/web/dist`）。

## 1. 静态托管对比

| 方案 | 免费额度 | 国内访问 | 部署方式 | 适合度 |
| --- | --- | --- | --- | --- |
| **GitHub Pages** | 无限流量（软限制） | 一般 | push 即部署，与仓库同源 | ★★★★★ |
| **Cloudflare Pages** | 500 次构建/月、无限带宽 | 较好 | 连 GitHub 或 CLI | ★★★★★ |
| **Netlify** | 300 分钟构建/月、100 GB | 一般 | 连 GitHub | ★★★★ |
| **Vercel** | 100 GB/月（个人） | 一般 | 连 GitHub | ★★★★ |
| **自建 VPS** | 无（约 ¥30–60/月） | 视线路 | 手动 | ★★ |
| **Gitee Pages** | 需实名与审核 | 好 | 手动 | ★★（需备案） |

**推荐**：主站用 **GitHub Pages**（零额外账号、CI 一体），国内太慢时把同一份 `dist` 接到 **Cloudflare Pages**。

## 2. 域名怎么最便宜

**完全免费**：平台子域 —— `<user>.github.io`、`<project>.pages.dev`、`<project>.netlify.app`。
自动 HTTPS、免备案（境外托管）、永久免费。

**注意**：Freenom 系免费顶级域（.tk/.ml/.ga）自 2023 年起已停止免费注册，**不存在免费 .com**。

**低成本正式域名（以后需要再买）**：

| 后缀 | 首年参考 | 续费参考 |
| --- | --- | --- |
| .top | ¥8–15 | ¥25–35/年 |
| .xyz | ¥10–20 | ¥70/年 |
| .dev | ¥80–120 | 同价（强制 HTTPS） |

建议先用免费子域；域名不影响任何功能。
