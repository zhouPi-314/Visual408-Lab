## 2. 逐项结论

### 2.1 OpenDSA —— 内容与练习的工业化组织

- **证据**：仓库根含 `AV/`（可视化）、`Exercises/`（练习）、`RST/`（教材正文源）、`SourceCode/`（代码示例）、`Metadata/`、`khan-exercises/`；MIT 许可证文件为 `MIT-license.txt`（版权 2011-2025 Ville Karavirta / Cliff Shaffer）。
- **可借鉴**：①「正文 / 可视化 / 练习 / 元数据」四件套分目录；②练习题与知识点用 id 双向绑定；③多语言代码示例与正文分离；④构建期把 RST 编译成静态站。
- **不要照搬**：教材正文可能由出版社另行授权，MIT 只覆盖代码。**我们只学结构**。
- **对我们的直接产出**：`content/<subject>/<module-id>/module.yaml + theory.mdx + sim.ts + tests.json` 的目录约定。

### 2.2 Algorithm Visualizer —— 「轨迹」而非「动画」

- **证据**：MIT；仓库根目录只有前端（`src/`、`public/`、`branding/`），未见执行/轨迹服务代码——与其「前端按 tracer 命令流重建可视化、执行侧独立部署」的架构相符（推断，需以官方文档复核）。其核心是让用户在代码里写 `tracer` 指令，运行后产生一串命令，前端按命令重建可视化。
- **可借鉴**：**把「执行」与「渲染」彻底解耦**——这正是我们 `frames[]` 事件轨迹模型的思想来源（见 `architecture-proposal.md` §4）。
- **注意**：主仓 2024-06 后基本停更，说明「代码轨迹可视化」在长周期维护上代价高；我们采用**预计算不可变轨迹**以降低维护成本。
- **不复用代码**：其前端耦合自身 tracer 协议，直接引入等于引入一套语义。

### 2.3 VisuAlgo —— 只做设计参考

- **证据**：站点无开源许可声明，交互页与题解为作者版权作品；GitHub 上无官方源码仓。
- **可借鉴**：①「滑块 + 单步」双模式；②同一数据结构的多算法并列对比；③测验模式与演示模式切换。
- **禁止**：复制其题目、动画资源、文案、配色与布局；不以其题库作为内容来源。
- **方法论**：只用人工观察到的**交互范式**，并在设计文档中注明「范式来自公开可见的交互，未复制实现」。

### 2.4 Ripes —— 处理器模拟器的教学分层

- **证据**：MIT；`src/` 下有 `cachesim/`、`isa/`、`assembler/`、`io/`，以及 `cachetab`、`memoryview`、`instructionmodel` 等视图；Qt 桌面应用。
- **可借鉴**：①**同一状态的多视图并列**（寄存器 / 内存 / Cache / 流水线）；②Cache 单独成 tab 且与内存联动；③「教学抽象模型 + 明确标注与真实机器的差异」。
- **不复用**：Qt/C++ 桌面栈与我们的 Web 栈不兼容；且完整 ISA 模拟远超 408 教学需要。
- **对我们的直接产出**：综合实验「虚拟地址访问链路」的分阶段视图（TLB → 页表 → Cache → 主存）。

### 2.5 408 复习可视化平台（ASD-0613）—— 最直接的同赛道竞品

- **证据**：MIT，7★，2026-10-19 推送；描述称 72 个交互模块 + 42 张理论卡，覆盖四科；**纯 HTML + JS，双击 `index.html` 即用**，唯一外部依赖是 Tailwind CDN；内置 2009–2026 真题与考纲 PDF，按真题考频排序模块。
- **值得学的**：①**真题考频驱动选题**（用数据决定先做哪个模块）；②「单步 + 回退 + 播放/暂停 + R」快捷键这套最小交互集；③理论卡与演示区同屏；④零构建的极低使用门槛。
- **明确不学**：**把历年真题与考纲 PDF 直接入库**——这正是我们 R-01 要避免的做法；我们也**不复制**其任何模块实现与文案。
- **差异化空间（重要）**：它没有跨学科链路实验、没有「事件轨迹 + 黄金用例」的确定性测试、没有代码视图联动、没有账号与进度、没有 i18n 结构。我们的定位应落在**深度与可验证性**，而不是模块数量。

### 2.6 Hello 算法 —— 许可陷阱

- **证据**：仓库 `LICENSE` 为 **Creative Commons Attribution-NonCommercial-ShareAlike 4.0**（非商业 + 相同方式共享）。
- **结论**：**不引入任何文本、图片、代码片段**。NC 条款会限制未来可能的商业化/赞助形态，SA 会把衍生内容一并纳入同许可。
- **允许**：作为个人学习材料阅读，理解其动画讲解节奏；不产生复制件。

### 2.7 Monaco Editor —— 代码视图底座

- **证据**：MIT，46.9k★，持续活跃。支持语义高亮、行装饰（decorations）、只读模式。
- **用途**：C++ 代码视图 + 当前执行行高亮 + 变量表旁的悬浮提示。
- **风险**：包体较大（数 MB），首屏需按需加载（动态 import + 独立 chunk）。
- **备选**：CodeMirror 6（更轻，但 `codemirror/dev` 已归档，需以 npm 包为准）。

### 2.8 Emscripten —— 浏览器内执行 C++ 的现实路径

- **证据**：MIT / UIUC-NCSA 双许可；持续活跃（2026-10-24 推送）。
- **用途**：**构建期**把预置 C++ 样例编译为 WASM，运行期在 Web Worker 中执行，输出事件轨迹驱动可视化。这样首版不需要服务端执行用户代码。
- **局限**：源码级单步调试（断点/变量/调用栈）在纯 WASM 方案里代价很高，**不承诺首版完成**（与规划文档一致）。
