# 查找：顺序 / 折半

## 顺序查找

从第一个元素逐个比较，最坏比较 n 次，平均 (n+1)/2 次。
对表是否有序**没有要求**，链表也能用。

## 折半查找

每次取区间中点与目标比较，砍掉一半：

```
low=0, high=n-1
while low <= high:
    mid = (low + high) / 2
    if a[mid] == target: 找到
    elif a[mid] < target: low = mid + 1
    else: high = mid - 1
```

比较次数上界约为 ⌊log₂n⌋ + 1。

## 两个前提（考试常考）

1. **表必须有序**；
2. **必须能随机访问**（顺序存储）——链表取 mid 是 O(n)，折半失去意义。
