# 二叉树遍历与递归栈

三种深度优先遍历的差别只有一个：**访问根结点的位置**。

```cpp
traverse(n) {
    if (!n) return;
    visit(n);              // 先序在这里
    traverse(n->left);
    visit(n);              // 中序在这里
    traverse(n->right);
    visit(n);              // 后序在这里
}
```

## 递归栈在做什么

每次 `traverse(child)` 都会把一个栈帧压入调用栈，返回时弹出。
所以：

- **栈深 = 还没返回的祖先个数**；
- 栈的最大深度不超过**树高**；
- 后序遍历时，访问根之前左右子树都必须返回过，栈里保留的是整条祖先链。

## 为什么中序非递归要用栈

中序要求「左子树全部完成 → 访问根 → 右子树」。走到最左边时，沿途的结点都还没访问，
必须**记住回来的路**，这就是显式栈存在的理由。

## 层序遍历

层序用的是**队列**而不是栈：先入先出才能保证按层推进。
