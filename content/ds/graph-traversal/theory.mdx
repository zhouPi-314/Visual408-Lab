# 图的遍历：BFS / DFS

## 两种策略，两个容器

| | 容器 | 过程 |
| --- | --- | --- |
| BFS | 队列（FIFO） | 访问起点 → 邻居全部入队 → 逐个出队继续扩散 |
| DFS | 栈（LIFO） | 访问起点 → 立刻深入第一个未访问邻居 → 走不通再回退 |

同一张图，从不同起点、不同邻接点顺序出发，遍历序列都可能不同——
**考试要求按邻接矩阵「下标从小到大」的顺序处理**，本例即如此。

## 例：0-1、0-2、1-3、2-3、3-4，从 0 出发

```
BFS：0 → 1 → 2 → 3 → 4
DFS：0 → 1 → 3 → 2 → 4
```

## 不变式

- 每个结点**最多访问一次**（靠 visited 数组）；
- 遍历生成树的边数 = 访问结点数 − 1（连通图）；
- BFS 得到的是**边数最少**的路径树；DFS 不保证。

复杂度：邻接矩阵 O(n²)，邻接表 O(n+e)。
