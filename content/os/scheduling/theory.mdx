# 进程调度：FCFS / SJF / RR

## 两个公式就够

```
周转时间 = 完成时间 − 到达时间
等待时间 = 周转时间 − 运行时间
```

平均等待、平均周转就是对所有进程取平均。

## 三种算法

| 算法 | 抢占 | 选择依据 | 特点 |
| --- | --- | --- | --- |
| FCFS | 否 | 到达顺序 | 简单；短作业被长作业挡住（护航效应） |
| SJF | 否 | 已到达者中运行时间最短 | 平均等待最短；长作业可能饥饿 |
| RR | 是（时间片到期） | 就绪队列 FIFO | 响应快；时间片过大≈FCFS，过小则切换开销高 |

## RR 的入队次序（考试常错点）

同一时刻既有人到达、又有人时间片到期时，约定是：
**新到达者先入队，被剥夺者排到队尾**。

举例（q=1）：P1(0,3)、P2(1,2)、P3(2,1)

```
t=0  P1 上 CPU
t=1  P2 到达 → 队列 [P2]；P1 时间片到期 → 队列 [P2, P1]；P2 上 CPU
t=2  P3 到达 → 队列 [P1, P3]；P2 到期 → 队列 [P1, P3, P2]；P1 上 CPU
t=3  P1 到期 → 队列 [P3, P2, P1]；P3 上 CPU 并完成
...
```

注意 t=2~3 跑的是 **P1** 而不是刚到 P3——这就是"轮转"而非"每次换人"。
