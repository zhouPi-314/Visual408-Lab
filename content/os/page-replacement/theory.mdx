# 页面置换：FIFO / LRU / OPT

物理块满了又发生缺页，就必须选一页淘汰。

| 算法 | 淘汰谁 | 是否栈算法 |
| --- | --- | --- |
| FIFO | 最早**调入**的页 | 否（会出现 Belady 异常） |
| LRU | 最久**未使用**的页 | 是 |
| OPT | 将来**最晚**才会用到的页 | 是（不可实现，只作理论上界） |

## 三个必须记住的坑

1. **命中时也要更新 LRU 次序**，否则 LRU 会退化成 FIFO。
2. **FIFO 的淘汰依据是装入时间，不是使用时间**。
3. Belady 异常只出现在非栈算法上：经典用例 `1,2,3,4,1,2,5,1,2,3,4,5` 在 FIFO 下 3 帧缺页 9 次、4 帧反而 10 次。

## 记号

- 引用串长度 = 总访问次数
- 缺页率 = 缺页次数 / 访问次数
- 命中率 = 1 − 缺页率
