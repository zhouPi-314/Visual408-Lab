# 组相联与全相联映射

## 三个数先算清楚

```
组数   = 总行数 / 每组行数
offset = log2(块大小)
组号   = log2(组数)
tag    = 地址位宽 − offset − 组号
```

每组 1 路就是**直接映射**；每组 = 总行数就是**全相联**（只有一组）。

## 为什么能减少冲突缺失

直接映射里，两个块只要组号相同就必须互相踢出。
组相联给同一组留了 n 个位置（n 路），只要这 n 个块不同时来，就不会冲突。

代价：

| 相联度 | 冲突缺失 | 硬件代价 |
| --- | --- | --- |
| 1 路（直接） | 多 | 1 个比较器 |
| n 路 | 少 | n 个比较器并行 + 多路选择 |
| 全相联 | 最少 | 全部行并行比较，成本最高 |

## 淘汰策略

组内 n 路满且 tag 都不匹配时才淘汰，按 **LRU**（一帧里会标出被淘汰的是哪一路）。
