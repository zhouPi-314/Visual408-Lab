# Cache 直接映射与地址划分

直接映射 Cache 把主存的每一个块固定映射到唯一的 Cache 行：

```
行号(index) = 块号 mod 行数
标记(tag)   = 块号 / 行数
```

地址被切成三段：

| 段 | 位数 | 作用 |
| --- | --- | --- |
| tag | addrBits − offsetBits − indexBits | 判断这一行装的是不是我要的块 |
| index | log2(行数) | 定位到唯一一行 |
| offset | log2(块大小) | 块内偏移 |

## 为什么同一地址会两次缺失

第 1 次访问块 10 装入第 2 行；第 2 次访问块 26 也映射到第 2 行，把块 10 踢掉；
第 3 次再访问块 10 —— 该行现在是块 26，于是又一次缺失。这就是**冲突缺失**：
Cache 里有空位，但这个块只能放在被别人占着的那一行。

> 教学要点：命中与否取决于「该行当前的 tag」而不是「这个地址以前来过」。
