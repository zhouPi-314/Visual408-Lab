# 网络数据发送链路

一条消息从应用到网线，要经过四次"加壳"：

```
应用数据
  ↓ 加 TCP 头（20B）        ← 按 MSS 分段
TCP 报文段
  ↓ 加 IP 头（20B）         ← 按 MTU 可能分片
IP 数据报
  ↓ 加以太网头（14B）+ FCS（4B）
以太网帧
  ↓
物理介质
```

## 分段与分片不是一回事

| | TCP 分段 | IP 分片 |
| --- | --- | --- |
| 依据 | MSS（通常 MTU − 40） | MTU |
| 层次 | 传输层 | 网络层 |
| 结果 | 每段带自己的 TCP 头 | 每片带自己的 IP 头 |

分片的载荷必须是 **8 的整数倍**，最后一片可以不足。

## 同子网 vs 跨子网

```
目的 IP AND 掩码 == 本机 IP AND 掩码  →  同子网，直接投递
否则                                  →  交给网关
```

关键结论：**跨子网时，以太网帧的目的 MAC 是网关**，不是最终主机。
链路层只负责相邻一跳，最终主机在哪由后续路由器继续转发。

## 开销

每条消息在链路上的字节 =
有效载荷 + 段数 ×（TCP 20 + IP 20）+ 帧数 ×（以太网 14 + FCS 4）

小包发得越多，头部占比越高——这就是为什么 MSS 不能太小。
