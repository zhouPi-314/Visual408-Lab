# 程序执行链路

同一行 C++，在四个层次上都能看：

```
a[3] = a[3] + 1;                    ← 源程序
  ↓ 编译
lw / slli / add / lw / addi / sw    ← 6 条指令
  ↓ 流水
IF ID EX MEM WB（5 级）             ← 时空图
  ↓ 调度
时间片用完 → 保存现场 → 换进程      ← 进程视角
```

## 为什么要 6 条指令

一条语句里有四件事：**取下标、算地址、读元素、写回**。
每件事对应一条（或两条）指令，所以指令数远多于语句数——
这正是"高级语言一条语句 ≠ 一条指令"的直接原因。

## load-use 冒险

```
I4: lw   r4, 0(r3)     ; 读 a[i]
I5: addi r4, r4, 1     ; 立刻用 r4  ← 必须等 I4 的 MEM 段结束
```

数据要到 MEM 段末尾才拿到，所以 I5 的 EX 段必须推后 1 拍。这类冒险叫 **load-use 冒险**。

## CPI

```
CPI = 总周期 / 指令数
```

理想流水线 CPI ≈ 1；本例 6 条指令、2 次停顿 → 12 拍 → CPI = 2.00。

> 本实验的指令集与栈帧布局是**教学抽象**，与真实 x86/ARM 有差异，用于讲清楚"层次"而不是仿真硬件。
