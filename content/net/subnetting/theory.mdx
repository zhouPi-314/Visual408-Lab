# IPv4 子网划分

## 四个量，一条链

```
掩码     = 前 prefix 位为 1，其余为 0
网络地址 = IP AND 掩码        （主机号全 0）
广播地址 = 网络号不变、主机号全 1
可用主机 = 2^(32 − prefix) − 2
```

减 2 是因为：网络地址代表子网本身，广播地址代表"本子网所有主机"，两者都不能分配给某台主机。

## 例：192.168.10.130/25

```
IP      11000000.10101000.00001010.10000010
掩码    11111111.11111111.11111111.10000000   = 255.255.255.128
网络    11000000.10101000.00001010.10000000   = 192.168.10.128
广播    11000000.10101000.00001010.11111111   = 192.168.10.255
可用    192.168.10.129 – 192.168.10.254       共 126 台
```

## 特例

| 前缀 | 可用主机 | 说明 |
| --- | --- | --- |
| /31 | 2 | 点对点链路（RFC 3021，两端各一个地址，不保留网络/广播） |
| /32 | 1 | 单主机路由 |
| /30 | 2 | 传统点对点写法 |

考试通常按"减 2"的规则算，遇到 /31、/32 需按题目约定说明。
